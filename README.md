# HCFUD：Research on Heterogeneous Cross-Dimensional Fusion and Uncertainty-Modulated Decoupling Algorithm for Substation Anomaly Detection
This study developed a novel method for substation anomaly detection called heterogeneous cross dimensional fusion and uncertainty modulation decoupling, which is constructed by a carefully designed HCFF module and USSD mechanism. The experimental results on the substation anomaly target recognition dataset show that compared with several advanced methods, our method achieves better anomaly detection performance.
